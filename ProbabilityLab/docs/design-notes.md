## Adaptation

Atmospheric landscape imagery lives in the hero rather than behind plotted data. The experiment workspace uses solid readable surfaces, subtle borders, generous spacing and distinct empirical/theoretical/normal colors. Both themes retain keyboard focus, reduced-motion support and responsive controls. There are no remote fonts or runtime image-generation calls.

## Original asset provenance

Generated with the built-in image-generation tool. Original PNG files and compressed WebP derivatives are in assets/. The compressed images total approximately 365 KiB. Typography and controls are real HTML; there is no baked-in text.

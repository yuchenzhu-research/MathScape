# 骰子實驗室

這是單一 Worker 版本的歷史說明與效能基準；下方保留當時的功能、測試與操作紀錄，不代表目前版本。最新啟動方式與測試請查看[專案 README](../README.md)。舊測試產物只保留在本機，不納入 Git 倉庫。

繁體中文、離線可用的骰子機率與中央極限定理示範。沒有模型、API 或遠端字型，所有計算在本機瀏覽器內完成。

## 開啟

直接以瀏覽器開啟 index.html 即可使用。此模式採用分批計算，讓介面保持可操作。

建議使用 Node.js 啟動本機伺服器，以啟用 Web Worker 背景計算：

    cd /Users/yuchenzhu/Desktop/test
    npm start

然後開啟 http://127.0.0.1:4173 。伺服器只監聽本機，不對外開放。若連接埠被占用，可使用 PORT=4174 npm start。

## 參數

- 六面機率：各 0–100%。調整一面時，其他五面按原比例重新分配；若其他面都是零，則等分剩餘機率。
- 每組擲骰次數 n：1–100。
- 重複組數 M：1–100,000,000。滑桿採用對數刻度（100–1 億）；輸入框可以精確輸入組數。
- 隨機種子：可選固定的 32 位元無號整數，重現相同實驗。
- 顯示：總和、平均值、標準化 Z。
- 操作：開始／重新開始、暫停／繼續、擲一組、清除、逐組動畫。

主圖和四個對照圖分別抽樣 M 組。對照圖的 n 固定為 1、2、10、15，使用獨立偽隨機序列。因此總擲骰量為 M × (n + 28)，不只是 M × n。

大量組數需要實際計算時間；1 億是允許的上限，不代表所有設定都會即時完成。逐組動畫每秒約 10 組，大量實驗建議關閉。

## 正確閱讀

增加 M，實測相對頻率會更穩定；增加 n，非退化骰子的總和／平均值逐漸接近常態。總和的標準差是 √n·σ，平均值的標準差是 σ/√n。

藍線使用逐次卷積求得精確的離散機率，綠柱使用實際擲骰計數。黃色常態近似使用每柱區間的機率並包含連續性修正，不直接將密度當成機率。n 較小或機率極端時，近似可能很差；只有一面機率為 100% 時是固定值，不顯示常態線，也不能計算 Z。

預設圖軸聚焦主要分布並包含全部已觀測結果；可勾選完整可能範圍。空間不足時會合併相鄰的總和取值，工具提示顯示區間和出現組數。

只保留各總和的計數及最後一組骰子。資料量約與 n 成正比，不隨 M 線性增加。固定種子的結果不受分批大小或暫停時間影響。

## 測試

不需要安裝套件即可執行數學測試：

    npm test

瀏覽器測試需提供 Playwright 與 Chromium，執行 npm run test:ui。測試涵蓋固定種子、退化機率、切換統計量、逐組動畫、暫停／繼續、百萬組實驗、響應式佈局及直接開檔模式。

可使用 PLAYWRIGHT_CHROMIUM_EXECUTABLE 指定已安裝的 Chrome 執行檔。壓力測試執行 npm run test:stress，預設真的抽樣 1 億組；可用 STRESS_GROUPS 指定其他組數（至少 100 萬）。

## 檔案

- engine.js：機率、卷積、常態區間機率、固定種子的抽樣與頻數統計。
- worker.js：背景模擬、進度回報與暫停／繼續。
- app.js：前端互動、Canvas 圖表與分批計算備援。
- styles.css：深色響應式介面。
- server.cjs：無依賴的本機靜態伺服器。
